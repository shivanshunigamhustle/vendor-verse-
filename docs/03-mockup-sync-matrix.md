# Mockup Sync Matrix (web ↔ mobile)

Maps every feature in [01-feature-spec.md](01-feature-spec.md) to the screens that implement it on web and on mobile, and says what each mockup must change to match. **This is the work list for the mockup sync.** The web sync pass was done on 2026-10-30 (statuses below); the mobile columns were not changed in that pass.

**Basis of the statuses.** Read from the two screen registries (`web/src/registry.jsx`: 178 screens, `mobile/src/registry.jsx`: 162 screens) and the earlier gap analysis. Web statuses after 2026-10-30 were set from the code and a render check of every registered web screen; nobody clicked through the apps end to end, so treat a status as "what the registry and code show", not as a test result. Screen IDs are the registry IDs.

| Status | Meaning |
|---|---|
| Done | Screen exists and shows the feature's main rules. Mockup-level only; none of the apps has a backend. |
| Partial | Screen exists but a state, rule or sub-flow is missing, or it differs from the feature spec. |
| Missing | No screen. |
| Hold | Screen exists but the feature's phase or content is undecided (phase OPEN). Do not change it until the open decision is closed. |
| Unverified | Not found in the docs or registry; check the code before syncing. |
| N/A | Nothing to show in this phase. |

**Platform scope.** Both clients carry every P1 feature (D-013). P2 features are shown on both with a "Phase 2" badge (D-010). OPEN rows stay as they are.

**Vendor theme contrast update (2026-11-13).** F-VND-13: corrected the Midnight preset so the Vendor shell, header search, navigation, form controls and analytics use readable dark surfaces and text. Theme persistence, workspace geometry and functionality are unchanged; mobile parity remains outstanding per D-027.

**Vendor mobile overlay fix (2026-11-13).** F-VND-10: removed the backdrop blur from the open mobile navigation scrim so the dashboard behind the sidebar stays sharp. Menu dismissal and the overlay behavior are unchanged.

**Vendor mobile sidebar surface and spacing update (2026-11-13).** F-VND-10: the open mobile sidebar now uses an opaque, theme-matched canvas, fills the viewport height from the left edge, and uses consistent inner padding so dashboard content does not show through the navigation.

**Workspace theme control update (2026-11-13).** F-VND-13: removed the multi-palette picker from the Vendor, Agent and Business web workspaces; the existing persistent Light/Dark toggle remains. Previously saved extra palette choices resolve to their corresponding Light or Dark mode. Mobile files were not changed.

**Web responsive layout update (2026-11-13).** Shared screen headers and long labels now wrap instead of being clipped; content grids and dialogs stay within their available width; Vendor and Business navigation uses the responsive drawer; sidebar navigation can scroll; and the customer home hero and mobile card strips stay within the viewport while showing all cards. The layout pass covers the Customer, Vendor, Business, Sales Agent and Admin workspaces without changing routes, data, permissions or workflows. The mobile app was not edited; visual parity remains outstanding.

**Maintaining this file.** Run `python docs/tools/check_docs.py` after any edit. It fails if a registry screen is unmapped, a screen ID does not exist, or a feature ID is missing from either file. See [05-maintenance-runbook.md](05-maintenance-runbook.md).
